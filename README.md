# Evolução em Python — Sistema de Gerenciamento Escolar

Este repositório reúne três exercícios práticos desenvolvidos durante meu processo de aprendizado em Python, demonstrando minha evolução na construção de soluções utilizando lógica de programação, estruturas de dados e funções.

**Exercício 1 — Manipulação de listas e funções**

O primeiro exercício consiste em um sistema simples de análise de desempenho escolar. Utilizando listas para armazenar as notas de diferentes turmas, desenvolvi funções para calcular médias e contabilizar alunos aprovados, considerando a nota mínima 7.

Também pratiquei a utilização de `for`, `enumerate()`, `sum()` e `len()`, além da separação de responsabilidades por meio de funções.

**Exercício 2 — Introdução aos dicionários**

No segundo exercício, comecei a trabalhar com dicionários para representar os dados individuais de um aluno, incluindo nome, idade, cidade, turma e notas.

Essa mudança representa um passo importante na organização dos dados, permitindo relacionar diferentes informações por meio de chaves e valores.

Também explorei o reaproveitamento de funções desenvolvidas anteriormente, adaptando a lógica de cálculo de médias e contagem de aprovações para essa nova estrutura.

**Exercício 3 — Estruturas de dados aninhadas e consulta por identificador**

No terceiro exercício, ampliei a estrutura anterior para armazenar múltiplos alunos, utilizando identificadores únicos como chaves de acesso e dicionários internos para organizar seus respectivos dados.

Implementei uma consulta interativa por ID, permitindo recuperar informações específicas de cada aluno e utilizar suas notas como entrada para funções de cálculo e análise.

Essa etapa reforçou meu entendimento sobre acesso a dados aninhados, reutilização de funções e organização de informações.

**Objetivo do aprendizado**

O objetivo desta sequência foi compreender não apenas como escrever código em Python, mas principalmente como estruturar uma solução, reaproveitar funcionalidades e adaptar uma lógica existente conforme a complexidade dos dados aumenta.

Os exercícios fazem parte de uma jornada contínua de aprendizado, na qual busco desenvolver autonomia na resolução de problemas, melhorar a organização do código e construir uma base sólida para projetos mais complexos.
